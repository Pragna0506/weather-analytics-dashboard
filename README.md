# 🌦️ Weather Intelligence Platform

A Streamlit-based data analytics application that provides weather insights, climate trend analysis, and geographical visualizations through interactive dashboards and maps. The platform enables users to explore weather patterns, country demographics, and geographical data using intuitive and interactive visualizations.

🚀 Features

- 🌍 Geo Analytics – Interactive maps and location-based visualizations.
- 📊 Dashboard Analytics – Key metrics, country statistics, and data summaries.
- 🌦️ Climate Trends – Weather pattern analysis and trend visualization.
- 🧠 AI Insights – Population insights, regional comparisons, and data-driven observations.
- 📈 Interactive Visualizations – Dynamic charts, maps, and trend-based visual analytics powered by Plotly.

🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- PyArrow
  
📊 Datasets

The datasets used in this project were collected from Kaggle and include:

- Cities Dataset – Geographic information such as city names, countries, latitude, and longitude.
- Countries Dataset – Population, area, capital, continent, and regional information.
- Weather Dataset (2016) – Historical weather records used for climate trend analysis and visualization.
